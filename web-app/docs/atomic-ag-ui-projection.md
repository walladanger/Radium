# Optional AG-UI projection

Radium exposes an in-process, opt-in state projection through `subscribeAtomicAgUi` from the Tasks store. Native authenticated snapshot/SSE transport and revision-checked controller commands remain authoritative. The Tasks page offers a session-only toggle, default off. Disabling it stops projected delivery and leaves tasks and history intact.

The implemented subset uses `STATE_SNAPSHOT` with `snapshot.atomicControl`, and `CUSTOM` with name `atomic.control.transition`. Snapshot replaces projected state. Custom values carry sequence, eventId, eventType, and observed taskId/attemptId when present. Explicit agent_progress events also carry observed worker/service/model identities, stage, and stepIndex; these come from the trusted broker and do not expose generated reasoning. Sequence is a durable controller cursor; it is not a model-generated percentage. Native event identities are retained. Replay duplicates are ignored; re-enabling synchronizes from the current native snapshot. Consumer exceptions and mutations cannot change native Tasks state.

Snapshots copy explicit display fields. Transition payloads copy identity fields only. Hidden reasoning, arbitrary tool content, credentials, worker fencing tokens, and permission grants are omitted. Approval records are display state; accepting them still requires the canonical revision-checked authorization command. Cancellation remains a canonical controller command.

This is a state/custom protocol subset for compatible in-app consumers. It is not a server endpoint, complete AG-UI RunAgentInput executor, tool dispatcher, or alternative scheduler. No run lifecycle events are synthesized from durable task state because task, attempt, and model run have different identities. No new dependency was added. A future server adapter must negotiate its capabilities, authenticate delivery, preserve replay, and implement actual run lifecycle contracts before claiming complete executor compatibility. Recorded snapshots do not imply the host is online; consumers must use the native connection state.

Primary specifications checked 2026-10-03: [official events](https://docs.ag-ui.com/concepts/events) and [state management](https://docs.ag-ui.com/concepts/state). STATE_SNAPSHOT and CUSTOM field names and semantics follow those documents. Draft and reasoning events are outside this subset.
